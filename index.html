Graph intelligence layer — transaction fraud platform

Finding fraud rings that behaviour alone can't see

Coordinated fraud hides in plain sight: each transaction looks ordinary, but the accounts share a device. This console shows a controlled experiment testing whether transaction-network structure improves detection, and the case workflow built on top of it.

The experiment

Same model, same temporal split, same training rows. The only variable changed is the feature set. Ring recall is the diagnostic measure: it isolates coordinated fraud specifically, which is what the graph is meant to add.

Investigation console

Alerts are consolidated into cases around the entity that connects them — usually a shared device. Select a case to see its network, the evidence retrieved for it, and the transactions that triggered it.
